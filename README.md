## Что работает

Небольшой Go-сервис с `GET /health`: возвращает `200 OK` и `ok`. Поиск, объявления и модерация пока описаны в требованиях.

## Запуск

Нужны Docker с Compose и Make.

```sh
make up
curl -i http://127.0.0.1:18080/health
make down
```

Сервис доступен только на локальном интерфейсе. Если порт занят, можно выбрать другой: `APP_PORT=18081 make up`.

Для локального профиля Colima `distsys` команды можно запускать с `DOCKER_CONTEXT=colima-distsys`, например `DOCKER_CONTEXT=colima-distsys make up`. Профиль должен быть запущен заранее; команды проекта не меняют глобальный Docker context.
